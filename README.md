# Ethereum-Phishing-Detection
Machine learning project investigating Ethereum phishing address detection using transactional, structural, and temporal features. Implements feature engineering, multiple classification algorithms, sampling techniques, statistical evaluation, temporal stability analysis, and graph neural networks (GCN and GIN).
# Ethereum Phishing Detection

## Project Overview

This project explores the use of machine learning techniques to identify phishing activities associated with Ethereum transactions.

The aim is to investigate how machine learning can help distinguish between legitimate and phishing-related Ethereum addresses or activities.

## Objectives

- Explore and understand the Ethereum phishing dataset.
- Perform data cleaning and preprocessing.
- Carry out feature engineering.
- Develop machine learning models for phishing detection.
- Evaluate model performance using appropriate evaluation metrics.
- Examine the effectiveness of different approaches to phishing detection.

## Project Workflow

3. Data Cleaning and Preprocessing
